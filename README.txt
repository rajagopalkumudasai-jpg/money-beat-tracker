Money & Beat Tracker - Mobile Compatible Version

Changes in this version:
- Fixed Chrome mobile keyboard disappearing while clearing/typing.
- The table is NOT rebuilt on each keystroke.
- Amount fields use a normal numeric mobile keyboard.
- No up/down spinner arrows.
- Easier phone layout: each serial number becomes a clear card on narrow screens.
- Money Paid defaults to ₹30,000 and is editable.
- Beat Amount is manual.
- Net Amount = Base Amount - Beat Amount.
- Cumulative Beat adds row by row.
- After cumulative beat reaches/exceeds Base Amount, the NEXT row starts a new cumulative cycle.
- 30 rows, dates on the 10th of each month starting 10 Feb 2026.
- Local storage + CSV export.

For GitHub Pages:
Replace index.html, manifest.json and sw.js in your existing GitHub repository with these new files.
Commit the changes.
GitHub Pages will update the live website automatically.
